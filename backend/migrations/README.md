# 结构版本与顺序单存档

`src/models/tables.py` 定义关系结构，API 启动时创建缺失的表。此版本新增：

- `folio_orders`：一份已存档的上架顺序单，记录稳定键、批次、整单校验码、件数、段数、
  格式、状态（`staging` / `active`）与来源。
- `folio_segments`：顺序单的连续段，按 `(order_id, ordinal)` 唯一，保存顺位范围、原始行
  文本与段校验码。

旧版部署升级时，新表随启动自动创建；旧证据中的顺序单不必立即改写，可分批执行
`POST /orders/migrate?batch_size=10` 完成迁移。迁移进程可中断重跑：已存在的段不会重写，
整单校验通过后才原子切换为 `active`。需要版本化迁移脚本的独立部署，可按上表字段自行
准备等价 DDL。
